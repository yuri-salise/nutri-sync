# Evaluation Instruments & Data

Contains anonymized UAT evaluation data complying with RA 10173 (Philippine Data Privacy Act of 2012):
- `sus_responses.csv`: System Usability Scale (10 questions, N=5+ respondents, target mean > 80)
- `iso25010_responses.csv`: ISO/IEC 25010 Software Product Quality Evaluation (5 characteristics, 1-5 scale)
- `rag_benchmark_results.csv`: 30-meal evaluation comparing RAG vs Non-RAG baseline on Retrieval Recall@5, Macronutrient MAPE, and Latency (ms).
